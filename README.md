# Portfolio architecture — Wanja Ntalindwa

Site statique en français, conçu pour GitHub Pages. Aucun service externe ni installation ne sont nécessaires.

## Utilisation

Ouvrir `index.html` dans un navigateur. Les catégories, la recherche, le tri et les galeries fonctionnent également sans serveur.

## Hébergement GitHub Pages

Dans les paramètres du dépôt, rubrique **Pages**, choisir **Deploy from a branch**, branche **main**, dossier **/(root)**, puis **Save**.

## Modifier les projets

Le catalogue est contenu dans `projects.js`. Chaque projet comporte un identifiant unique, un nom, une période, une catégorie, une description, des chemins d’images, les crédits documentés et le champ `featured` pour la sélection d’accueil. Ajouter les images optimisées au dossier `assets/`, puis compléter le catalogue.

Les informations initiales proviennent de la liste de projets fournie, datée du 26 septembre 2026. Cette première version reprend les 35 projets A/B et les 4 portfolios déjà constitués ; les 31 entrées de complément de la catégorie C restent à développer. Les regroupements thématiques sont éditoriaux. Les descriptions du document source étant en partie déduites des dossiers, elles restent à valider par l’auteur.

Les contextes de collaboration connus sont indiqués dans les fiches, sans attribuer à l’auteur un rôle précis non documenté. Le projet Mangembo conserve la mention de rendu « by BM » du document source. Vérifier les crédits et les autorisations avant toute réutilisation des visuels hors de ce portfolio.

## Fonctions

- Sélection de projets et collection complète.
- Catégories avec compteurs, recherche sans distinction d’accents, tri par date ou par nom.
- Fiches et galeries, navigation au clavier, retour au projet après fermeture.
- Mise en page adaptative, images WebP et chargement différé.
- Liens de contact par e-mail. Aucune collecte ou transmission automatique.

Les images sont des copies optimisées des documents et dossiers fournis. Aucun fichier source n’a été modifié. Ce dépôt n’inclut aucun dossier administratif, plan d’exécution, adresse locale ni fichier de travail BIM.
